# 详细需求测试：虎牙“我的”页改版竞品参考

## 输入与目标

用户给出的详细需求是：

> 这是我们现在的“我的”页现状，我需要做一个改版，优化方向是简化布局，突出常用功能，并且强化会员、任务中心模块，其他的功能收起来。根据这个目标帮我搜集可以参考的竞品页面。

任务因此同时保留了当前产品页面作为基准，并搜集可用于改版参考的竞品页面；阅读报告时不要把“当前页面”误认为竞品素材。

## 结果

- 最终报告：[`report.html`](./report.html)
- 报告数据：[`report_data.json`](./report_data.json)
- 报告说明：[`阅读说明.md`](./阅读说明.md)
- 报告使用的本地截图：[`assets/`](./assets/)
- 结果包含 9 个产品、10 张单屏截图；其中包含当前虎牙页面，以及 B 站、腾讯视频、豆包爱学、Headway、斗鱼等改版参考。
- 报告中的主要建议围绕三类结构：会员/常用入口层级、任务/成长反馈、低频服务收纳；具体判断以报告正文和分类文件为准。
