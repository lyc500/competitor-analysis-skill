# 证据边界

本轮目标是修正 Skill 的契约与交接，而不是重新搜集某一类产品。所有“通过”均按证据类型限定：

- `contract`: 结构、ID、URL 角色、状态、候选上限和统计约束由 Python 校验。
- `fixture`: 使用仓库测试图片或本地测试网页，不能证明公开来源可用。
- `static`: 文档关键词测试只能证明规则已声明，不能证明规则被真实执行。
- `browser_local`: 真实 Chromium 操作了本地测试报告和本地 HTTP 页面，验证交互/截图工程链路，不代表真实第三方来源验收。
- `manual_external`: 本轮未执行，因此不标记通过。

旧验收目录只用于定位历史证据缺口，不作为本轮输入。没有可靠关联的旧截图、候选、URL、分类和运行记录不被迁移或修复成新证据。
