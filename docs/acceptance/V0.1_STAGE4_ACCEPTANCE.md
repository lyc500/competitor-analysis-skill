## 本轮范围

Stage 4 消费 Stage 3C 的 `reviewed_materials.json` 和 Agent 生成的 `classification-plan.json`，过滤真实有效 collected Materials，复制图片到独立报告 `assets/`，生成 `classification.json`、`report_data.json` 和 HTML 图墙。分类器与报告不重新执行采集、语义审核或机械校验，不进入 Stage 5。

## Classification Plan Contract

计划必须提供非空 `classification_dimension`、`classification_reason`、唯一分组名称、非空分组原因和 `material_ids`。每个有效 collected Material 必须且只能出现在一个分组；不得引用 rejected/pending/unavailable 或未知 ID。`material_labels` 的 labels 为字符串键值，并原样保留。Python 不根据产品类型、notes 或关键词推断分类。

## 报告与状态边界

主图墙只展示同时满足 semantic accepted、quality accepted、collection collected 且路径有效的素材。Stage 4 将图片复制到自身 `assets/`，因此移动整个输出目录后报告仍可用。无有效素材时输出 `unavailable`，不生成空图墙，并展示 fallback 中的 open 项；resolved 项不作为缺失项展示。报告自身再次执行 collected-only 防御性过滤。
