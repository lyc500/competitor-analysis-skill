## 本轮范围

## Browser Capture 契约

每条结果保留 `source_candidate_id`、`requested_url`、`final_url`、产品/目标页、页面标题、HTTP 状态、内容类型、Chromium 版本、viewport、采集时间、截图路径、机械质量字段和 `capture_status`。状态仅为 `captured`、`blank`、`failed`，不含 `semantic_status`、`semantic_reason` 或 `collection_status`。

## 浏览器与安全策略

使用 Playwright `1.60.0` 与 Chromium `148.0.7778.96`（Playwright bundled browser）。采用 headless Chromium、`domcontentloaded`、有限 `networkidle` 等待和 settle 延迟；networkidle 超时不直接判失败。截图复用 Pillow 阶段 2 机械检查。正式流程仅允许公网 DNS/IP，拒绝 localhost、私网、保留/链路本地地址，并拦截重定向到非公网地址；测试通过内部 `allow_private_network=True` 使用本地 HTTP fixture，未暴露为 CLI 开关。

## 测试结果

新增真实 Chromium 测试覆盖静态页面、动态标题等待、HTTP 404、空白页面、单来源失败隔离、来源追溯、viewport、机械 PNG 解码和默认 public-only 拒绝；另有 CLI 参数约束与 pipeline 不污染 Material 测试。`python3 -m unittest discover -s tests -v` 实际 45 项通过；其中 `tests/test_capture_workflow.py` 的 5 项测试覆盖真实 Chromium/本地 HTTP Server 场景，不依赖公网。
