仅接受带 hostname 的绝对 `http`/`https` URL，拒绝凭据、相对路径、`javascript:`、`data:` 和 `file:`。scheme/hostname 小写，移除默认端口和 fragment，空路径统一为 `/`，query 原样保留。去重 key 为标准化竞品名和标准化 URL；不同竞品引用同一 URL 保留两条关系；ID 根据竞品、目标页和标准化 URL 哈希生成。
