# V0.1 阶段 1 验收记录

验收阶段：需求理解与竞品规划
基线：`08599cb5d97d32f582d31bbe411b312b2967188b`

## 验收边界

本阶段只验证结构化任务契约、任务状态、用户指定竞品保留与排序、Agent 补充竞品标记、地区假设/澄清、正式 `--task-file` 入口和 fixture 显式入口。不实现图片下载、截图、机械图片质量校验、页面语义判定、动态分类或 HTML 优化。

上一版未通过的原因是正式路径仍由关键词和固定产品名单生成任务，且没有正式的 Agent 结构化任务入口。本次补正移除了正式 `plan_competitors()` 中按页面类型生成名单的逻辑；固定目录仅保留在显式 `fixture=True` 且 `planning_strategy=fixture_demo` 的路径。Agent 任务通过 `load_task()`/`load_task_file()` 校验后进入 pipeline，Python 只做契约校验、去重、指定竞品置前、确定性排序和持久化。

## 职责区分

- Agent/Skill 应负责理解用户真实目标、识别目标页面、提取用户指定产品、规划补充竞品、记录假设，并产出结构化任务。
- Python 已真实实现并测试任务字段/状态/来源的一致性校验、用户指定竞品优先排序、竞品计划持久化和明确验收短语的输入适配。
- 测试 fixture 包括显式 `fixture_demo` 任务和离线结构化断言；fixture 不代表 Agent 已完成通用语义推理，也不代表真实采集成功。
- 当前仍未实现通用模型驱动的自然语言理解、浏览器截图、用户上传、真机补充、图片质量和页面语义确认。
