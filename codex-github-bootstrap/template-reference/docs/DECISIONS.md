---

## 使用规则

每个重要决策使用以下格式：

```text
## D-001 决策名称

日期：
状态：已确认 / 待验证 / 已废弃

### 决策

最终确定采用什么方案。

### 原因

为什么选择这个方案。

### 放弃的方案

有哪些备选方案没有采用。

### 影响范围

该决策会影响哪些页面、功能或技术实现。
```

## D-001 示例：横向竞品对比采用截图墙

日期：YYYY-MM-DD  
状态：已确认

### 决策

同类竞品页面采用统一尺寸截图墙进行横向展示，每张截图支持点击放大。

截图墙下方统一输出差异总结，不在每张截图旁堆叠大量文字。

### 原因

核心目标是降低设计师横向比较不同产品 UI 的认知成本。

如果分析文字直接和截图混排，会导致页面过长，难以形成快速视觉对比。

### 放弃的方案

每个竞品单独形成一个完整分析章节。

原因：阅读路径过长，不适合作为横向决策工具。

### 影响范围

- 竞品报告页面
- 图片预览组件
- 分析内容结构
- 报告生成逻辑
